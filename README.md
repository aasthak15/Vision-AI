## 📌 Project Overview

Visually impaired individuals often rely on other people to understand their surroundings, recognize familiar individuals, read visible information, and identify objects around them.

**Vision AI** is a multimodal assistive system designed to act as an intelligent voice-based companion. It combines **computer vision, speech recognition, facial recognition, image analysis, and generative AI** to help users understand visual information through natural voice interaction.

The system captures an image using a camera and allows the user to interact with the captured scene through spoken commands.

Depending on the user's request, the system can:

- Describe the captured scene using a vision-language model.
- Recognize a person using facial recognition.
- Read textual information using an OCR-based module.
- Support currency identification through a dedicated vision model.
- Convert AI-generated responses into speech.
- Allow users to ask questions about the captured image.

The overall interaction follows a simple:

**Voice → Vision → AI Analysis → Response → Speech**

pipeline.

# 🎯 Objectives

The primary objectives of Vision AI are:

- To provide an AI-powered visual assistant for visually impaired users.
- To enable hands-free interaction through voice commands.
- To capture and analyze real-world images.
- To generate natural-language descriptions of visual scenes.
- To identify known individuals using facial recognition.
- To provide text-reading capabilities through OCR.
- To support currency identification.
- To convert visual analysis into understandable spoken responses.
- To create an extensible platform for assistive computer vision applications.

# ✨ Key Features

## 🎙️ Voice-Based Interaction

The system accepts spoken commands from the user and converts the spoken input into text using speech recognition.

Example commands:

```text
"Hey Vision"
"Describe this"
"Who is this person?"
"Read this"
"Detect currency"
```

##📷 Image Capture

The system captures an image using a connected camera.

The captured image becomes the input for the appropriate computer vision or AI module based on the user's request.

##🧠 AI-Powered Image Description

A multimodal generative AI model can analyze the captured image and provide a natural-language description.

The system can be used to understand:

Objects present in a scene
People and their appearance
Surrounding environment
General visual context
Information requested by the user

Users can also ask follow-up questions about the captured image.

##👤 Facial Recognition

The system uses DeepFace for facial recognition.

When the user asks to identify a person, the captured image can be compared against a database of known faces.

Workflow:
```text
Camera Image
     ↓
Face Detection
     ↓
DeepFace
     ↓
Comparison with Known Faces
     ↓
Recognition Result
     ↓
Voice Response
```
##🔤 OCR / Text Reading

An OCR module can be integrated to extract text from captured images.

Workflow:
```text

Captured Image
     ↓
OCR Processing
     ↓
Text Extraction
     ↓
Text Understanding
     ↓
Speech Output
```
This functionality can help users access information displayed on:

Signs
Documents
Product labels
Menus
Printed material
Digital displays

##💵 Currency Detection

A dedicated computer vision model can be integrated to identify currency from a captured image.

```text
Camera
   ↓
Captured Image
   ↓
Currency Detection Model
   ↓
Currency Classification
   ↓
Speech Output
```

##🔊 Text-to-Speech

Responses generated by the AI system are converted into speech using gTTS (Google Text-to-Speech).

This allows users to receive information through audio instead of relying on a visual interface.

##🗜️ Image Compression

Captured images can be resized and compressed before being processed by AI services.

Image compression helps to:

Reduce image size
Reduce network usage
Improve processing efficiency
Meet API image-size requirements

##🧩 Core Software Modules

#record_audio()

Captures audio from the microphone and converts the spoken input into text.

Responsibilities
Initialize speech recognition.
Capture microphone input.
Convert speech into text.
Handle speech recognition errors.


#capture_image()

Captures an image using the connected camera.

Responsibilities
Trigger the camera.
Capture the image.
Store the captured image.
Pass the image to preprocessing.

#compress_image()

Reduces the dimensions and size of captured images.

Responsibilities
Open the captured image.
Resize the image.
Save the compressed image.
Prepare it for AI processing.

#find_match()

Performs facial recognition using DeepFace.

Responsibilities
Load the captured image.
Load known face images.
Compare faces.
Determine whether a matching face exists.
Provide the recognition result.

#call_api_with_gemini()

Sends the processed image and user's request to a multimodal generative AI model.

Responsibilities
Configure the AI service.
Prepare the image input.
Send the user's prompt.
Receive the generated response.
Pass the response to text-to-speech.

#text_to_speech()

Converts generated text into spoken audio.

Responsibilities
Convert text into speech.
Generate an audio file.
Play the generated response.
